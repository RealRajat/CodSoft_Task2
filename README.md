## Features

- Add tasks to a visible list
- Select and delete a task
- Mark a selected task as completed
- Basic input interaction through a desktop GUI
- Error dialogs when an action requires a task selection

## Tech Stack

- Python
- Tkinter
- Tkinter message boxes

## Getting Started

### Prerequisites

- Python 3 installed

### Run

```bash
git clone https://github.com/RealRajat/CodSoft_Task2.git
cd CodSoft_Task2
python ToDoList.py
```

## How to Use

1. Type a task into the input field.
2. Select **Add task** to add it to the list.
3. Select a task and choose **Mark task as done** to mark it complete.
4. Select a task and choose **Delete task** to remove it.

## Learning Outcomes

- Organizing application logic with a Python class
- Building interactive desktop interfaces
- Managing list-based application state
- Handling selection errors with message boxes
